# Physics-Informed Neural Networks for Urban Air Pollution Modelling

This project applies Physics-Informed Neural Networks (PINNs) to model and predict urban air pollution using environmental data and deep learning techniques.
## Features
- Urban air quality prediction
- Physics-informed learning
- Data preprocessing and visualization
- Neural network modelling

## Technologies
- Python
- TensorFlow/PyTorch
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## Repository Structure

PINN_Urban_Air_Quality.ipynb -> Main notebook

## Installation

pip install -r requirements.txt

## Usage

Open the notebook:

PINN_Urban_Air_Quality.ipynb
